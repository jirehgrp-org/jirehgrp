# JirehGroup Website

**Official website of JirehGroup — Showcasing innovation in software, AI, and technology services.**

This is the internal codebase for JirehGroup’s corporate website. Built with a modern tech stack and a strong emphasis on design, performance, and maintainability, it serves as the digital face of our company and communicates our mission to clients, partners, and the tech community.

---

## About JirehGroup

JirehGroup drives innovation through expert software development, cutting-edge AI solutions, research initiatives, and a wide range of technology services. The website reflects our capabilities, offerings, and commitment to quality and creativity.

---

## Tech Stack

- **Next.js** – React framework for server-rendered and statically generated applications  
- **React Hooks** – For managing state and component lifecycle in a clean, functional style  
- **Tailwind CSS** – Utility-first CSS framework for rapid and responsive UI development  
- **shadcn/ui** – A customizable component library for building consistent, accessible UIs  
- **Custom UI Components** – Designed in-house for branding and unique interface needs  
- **Additional UI Libraries** – Selectively integrated for specific interactions and layouts  

---

## Project Structure

```bash
/app            # Application routing and page-level logic  
/components     # Reusable UI and layout components  
/styles         # Tailwind config, global styles, and design tokens  
/lib            # Utility functions and shared logic  
/public         # Static assets (images, icons, etc.)
```
